# TruckLook

**Разработано ErcanDuman.**

[English](../README.md) · [Deutsch](README.de.md) · [Français](README.fr.md) · Русский · [Español](README.es.md) · [Português](README.pt.md) · [中文](README.zh.md) · [Türkçe](README.tr.md)

TruckLook преобразует движения головы и глаз, полученные со стандартной веб-камеры, в плавное движение камеры кабины в Euro Truck Simulator 2 и American Truck Simulator. Данные отслеживания локально передаются в OpenTrack по UDP, а затем предоставляются игре как TrackIR.

## Возможности

- Отслеживание положения головы и направления взгляда с помощью радужки
- Пятисекундная визуальная калибровка; затем предпросмотр камеры скрывается для снижения нагрузки на отрисовку
- Запрос видеопотока до 120 FPS и интерполированный выход OpenTrack 120 Гц
- Настраиваемая чувствительность головы, вклад взгляда, сглаживание и мёртвая зона
- Независимая инверсия осей рыскания, тангажа и крена
- Интерфейс на английском, немецком, французском, русском, испанском, португальском, китайском и турецком языках
- Локальная обработка; кадры камеры не записываются и не отправляются в интернет

## Требования

- Windows 10 или Windows 11
- Веб-камера
- Euro Truck Simulator 2 или American Truck Simulator
- [OpenTrack](https://github.com/opentrack/opentrack/releases)

## Установка и настройка OpenTrack

1. Скачайте и запустите `TruckLook-0.2.0-x64.exe` со страницы GitHub Releases.
2. Установите и откройте OpenTrack.
3. Установите **Input** в значение **UDP over network**, а порт — `4242`.
4. Установите **Filter** в значение **None**.
5. Установите **Output** в значение **freetrack 2.0 Enhanced** и включите интерфейс TrackIR.
6. Нажмите **Start** в OpenTrack.
7. Откройте TruckLook, выберите веб-камеру и нажмите **Запустить отслеживание**.
8. Во время пятисекундной калибровки смотрите в центр экрана, затем запустите ETS2/ATS.

Переменная конфигурации игры `g_trackir` должна быть равна `1`. Сначала оставьте кривые OpenTrack линейными: TruckLook уже фильтрует положение и формирует поток 120 Гц, поэтому второй фильтр может увеличить задержку.

## Использование TruckLook

Предпросмотр камеры отображается только во время калибровки. Через пять секунд он скрывается, а отслеживание продолжает работать в фоновом режиме. Нажмите **Центрировать**, чтобы снова показать камеру на пять секунд и задать новое центральное положение.

| Настройка | Назначение |
| --- | --- |
| Чувствительность головы | Умножает физический поворот головы |
| Вклад взгляда | Добавляет направление взгляда по радужке к движению камеры |
| Сглаживание | Уменьшает дрожание; высокое значение даёт стабильность, но увеличивает задержку |
| Мёртвая зона | Игнорирует очень малые движения возле центра |
| Инверсия осей | Отдельно меняет направление влево/вправо, вверх/вниз или крен |

Значение FPS в интерфейсе показывает фактическую частоту обработки камеры. TruckLook запрашивает до 120 FPS, но итоговая частота зависит от веб-камеры, драйвера, освещения и производительности компьютера. Выход OpenTrack продолжает интерполироваться до 120 Гц.

## Разработка

Требуется Node.js 20 или новее.

```powershell
npm install
npm run dev
npm test
npm run package
```

Переносимый исполняемый файл Windows создаётся в `release/`. Файлы MediaPipe WASM копируются из npm-зависимости во время сборки. Модель Face Landmarker загружается во время работы с официального адреса Google и не распространяется в этом репозитории.

## Публикация на GitHub

После упаковки выполните `npm run prepare:github`. В репозиторий исходного кода добавляйте только содержимое `github-upload/`. Содержимое `github-release/` прикрепляйте к GitHub Release, не добавляя исполняемый файл в историю Git. Точные команды приведены в [руководстве на турецком языке](../GITHUB_UPLOAD_GUIDE_TR.md).
